# Tugas Point Operation: Contrast Stretching

Penerapan point operation (contrast adjustment) pada citra digital menggunakan Python.

## Metode
Contrast stretching: g = (f - min) / (max - min) x 255

Nilai piksel direntangkan ke seluruh rentang 0 sampai 255 sehingga perbedaan
terang dan gelap pada gambar menjadi lebih jelas.

## Alur
1. Citra berwarna (RGB) diubah ke grayscale (luminosity)
2. Contrast stretching
3. Perbandingan gambar dan histogram sebelum dan sesudah
